## ⚡ Modern Architecture: Astro + Tailwind CSS

This portfolio has been completely modernized from its 2021 foundation into a blazing-fast, responsive web application powered by **Astro 5** and **Tailwind CSS**:

- **100/100 Lighthouse Performance:** Pure static HTML/CSS generated at build time with zero unnecessary client-side JavaScript.
- **Component-Driven Structure:** Clean Astro components for the Hero, BIM & AEC Automation, Project Showcases, Capabilities, and Contact.
- **Privacy-First Communication:** Replaced exposed personal phone numbers with direct **Calendly 15-minute booking**, encrypted email, and GitHub links.
- **Automated CI/CD:** Native GitHub Actions workflow (`.github/workflows/deploy.yml`) using `@withastro/action` to automatically build and deploy changes to GitHub Pages upon pushing to `main`.

---

## 🏗️ BIM & AEC Automation Capabilities

- **Dynamo Scripts for Autodesk Revit:** Algorithmic model auditing, parametric modeling, automated sheet creation, and quality assurance.
- **ACC Cloud Automation (formerly Forge):** Python cloud pipelines utilizing Autodesk Construction Cloud APIs for automated file upgrades, model synchronization, and metadata validation.
- **Revit Add-ins (C# & pyRevit):** Production engineering plugins built with C# (.NET / Revit API) and pyRevit, featuring custom ribbon extensions, automated wall adjustments, and batch detail importers.
